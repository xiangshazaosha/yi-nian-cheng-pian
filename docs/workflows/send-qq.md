# QQ「我的手机」发送正式成片

仅用户明确要求发送时读取与执行；完成成片不自动触发。本节不是 Computer Use 的永久授权，仍须先说明无合适替代路径的原因并取得用户明确同意；还须确认当前工具确实支持该操作。

1. 按[审片与交付目录规则](../../remotion-clone/review/workflow-flash/README.md)，从 `deliverables/final-videos/<片名>-<风格名>/` 与 `project.json.finalVideoVariants` 确认唯一正式成片，核对存在、文件名和大小。不得误发审片、旧版或其他风格，不固化安装盘符或坐标。
2. 先查已打开的 QQ 窗口，直接进入「我的手机」。QQ 运行但无主窗口时，通过通知区域企鹅图标恢复，必要时展开隐藏图标菜单；位置变化不能靠固定坐标。未登录时不代用户登录。
3. 点击「文件」，在系统文件选择框的「文件名」输入已核对成片完整路径并确认。
4. 二次确认框核对「发送给 我的手机」、文件名和大小，再点「发送」。只发一次，不另发文字或其他素材。
5. 等到该文件消息显示「已发送」才报告成功。仍在进度中、弹窗未关闭或无法验证时，不声称已发送，也不盲目重试造成重复发送。
