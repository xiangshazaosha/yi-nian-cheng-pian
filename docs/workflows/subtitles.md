# 字幕时间轴与校正规则

本文件是字幕来源、校正、时间轴、文字职责及裸排边界的权威规则。字幕任务与进入包装规划前必读；不要求为校字幕加载风格或包装组件库。

## 来源与校正

- 优先使用已有 `SRT / VTT / ASS / 带时码 JSON / 剪辑软件字幕时间轴`，正文和起止时间以该权威源为准。禁止根据策划稿、口播印象或人工概括编写替代字幕。
- **先校正，再规划与制作**：保留原件，另存校正版与逐条差异记录（编号、时间码、原文、校正文、依据）。只修正有依据的误识别、错别字、术语和标点，不做摘要式改写。
- 疑难词、重复句、异常短句须核对对应音频；不能确定的标记待确认，不猜改。默认保留条目和起止时间；必要的时间轴修复须记录音频对齐证据及前后差异。校正版成为后续权威源；未决项未清零不得输出最终成片。
- 上述最终字幕清零要求不等于禁止交付可编辑粗剪草稿。粗剪阶段无法核实的个别术语保留原声与原始转写、记录未决，不猜改、不冒称已校正；能否交草稿统一按[粗剪闸门](./rough-cut-defaults.md#能力检查与交付闸门)。若误识别影响删留判断，先保留该处或核实，不能以未校正文本为由删除独有信息。
- 原项目无时间轴时，先转写并音频对齐，保存带起止时间的字幕文件；用于成片前明确告知用户“原项目无时间轴字幕，现已新建字幕时间轴”及其路径。未建立并告知前不得自行编字幕进入渲染。
- 乱码先检查原始字节、BOM 和明确编码（如 UTF-8、UTF-8 BOM、GB18030）。终端显示异常不等于源文件损坏，不能因此改用人工概括。

缺少时间轴、确需 ASR 时，按[转写入口](./video-editing.md#1-原素材转写固定入口)选择通道；单独校正已有字幕不加载 ChatCut 或本地 Whisper 操作细节。

### 用户已确认的口播习惯

- **“哎 喂”**：用户常用的两个独立语气词，字幕在中间保留一个空格，不连写为“哎喂”，不凭发音相似猜改成“AI”或专业术语。默认保留其语气与原声，不在去口癖／粗剪时一律删除；只有用户明确要求删除该处时才处理。此条是该用户已确认的口播习惯，不推广为其他说话人的发音判断。

## 时间换算与检查

- 连续源时间轴的包装分段只做固定偏移：`localTime = sourceTime - segmentStartTime`，再按目标 fps 换算帧；不改写原句，不按感觉重分时长。
- 删除或重排的时间映射按[剪辑数据协议](./editing-contract.md)逐段登记，须有剪辑与音频对齐证据，不能套用一个总偏移掩盖多个切点；只有实际剪辑／重映射任务才读取该协议，普通校正不强制建立剪辑计划。
- 渲染前至少抽查段首、中段、段尾，对照源原文、起止时间及当前段固定偏移。

## 字幕与包装文字分层

- `subtitle` 逐字同步口播，来自权威时间轴，位于字幕安全区；不承担观点概括。
- `title / keyword / summary / label` 属于包装设计层，可以语义提炼，但必须对应当前已说到的句子或信息段，不能提前展示后句才成立的结论。
- 禁止把整句字幕复制放大后冒充设计标题；代码和规划必须标注文字角色，分别验证字幕忠实度与包装语义。

## 显示边界

- 逐字字幕默认裸排，不加圆角底板、边框、卡片阴影或卡片内边距。先用安全区、字色及克制的字形描边／投影保证可读性；只有用户明确要求底板时才记录片级例外。
- 包装卡片须有独立对象身份且确有必要，使用所选风格令牌，不借字幕样式冒充包装。
- B-roll 有烧入字幕的区间隐藏重叠的 Remotion 字幕，交接时不以淡化重叠的方式残留第二层；保留烧入字幕内容，不覆盖或裁掉。
- 字幕与人物、ROI、标题及图表的具体避让在[内容规划](../02-content-planning.md)阶段决定，字幕显示问题只读取相关段，不默认加载全部包装方案。
