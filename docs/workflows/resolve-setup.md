# Resolve：安装与环境接入

仅用户已选择达芬奇且确需安装、修复或接入环境时读取；正常剪映任务不进入。先确认实际已安装状态，不能根据历史“尚未安装”重跑安装。安装或选择工具均不授权界面控制、登录、购买或接受未确认许可。

达芬奇主程序目标位置为 `tools/davinci-resolve/`，安装包放 `tools/installers/`；细则见[软件目录](../../tools/README.md)。不用第三方重新打包安装器，不绕过许可证。操作系统安装记录／SDK／驱动等不能定制目录的项目必须说明。

### 官方免费版下载：简短实现方法

1. API 取包失败且用户明确允许浏览器操作后，打开 [Blackmagic 官方产品页](https://www.blackmagicdesign.com/products/davinciresolve)。
2. 点击 `DaVinci Resolve → Free Download Now`，在**免费版**区域选 `Windows x86`，不选 Studio 或 Windows ARM；版本以当前网页为准。
3. 每步以最新页面确认结果。出现必填个人资料时保留页面、请用户自行填写并提交；不编造资料、不代登录，不将登记内容写入项目。
4. 以下载完成及本地文件为准，将官方安装包保存到 `tools/installers/`；仅打开登记表不算下载完成。核验安装器签名后再运行。
5. 主程序安装目标为 `tools/davinci-resolve/`；安装器若强制写入其他位置或要求接受许可条款，先告知并在对应闸门取得确认。安装后检查实际版本与官方脚本连接，再测试可编辑工程，不从安装成功推导自动化可用。

内置浏览器连接失效时，只有用户明确指定／允许后才切换已有 Kimi WebBridge；不安装第二套浏览器控制工具。沿用其技能，用同一任务 session／标签组、Windows 独立 UTF-8 请求文件调用，并及时删除请求文件。优先用 `snapshot` 的当前元素引用操作，只回传下载相关节点；长页面截断时按实际可见控件读取必要 DOM，不加载全网页正文。产品页入口未完成时可进入官方支持页，选最新**非 Studio**版本的 Windows x86 下载按钮。

官网若已经显示 `Thanks` 和安装包链接，不再要求用户重填登记资料，也不假称由 AI 填写。从当前最前层可见下载链接取得官方 URL，检查域名，直接保存到项目安装包目录；签名下载 URL 只留在忽略的临时证据中，不放进公开文档。网页成功提示与实际文件下载完成分开验证。

## 安装后的接续

核验实际版本、签名与连接能力，再转[可编辑执行与验收](./resolve-editing.md)。同环境失败需要历史依据时才查[安装与接入记录（未随公开版分发）](../public-release-scope.md)，不要从下载成功推导执行能力。
