# 公开版能力与验收边界

当前基线是 Windows x64，按需部署和本地 ASR 优先。核心剪辑/时间轴/字幕适配器、草稿生成器和 Desktop MCP 桥具有对应测试；测试通过不等于已替用户安装软件或完成真实推理。

Desktop 桥当前复用 Codex app-server，不承诺其他 Agent 的工具传输兼容。macOS、Linux、ARM64、CUDA/Metal 引擎切换及其他宿主需要独立适配和验收。可选 Resolve 按其操作包和当前实际能力判断，作者机器的历史回执不作为新用户证据。

未使用历史媒体工程验收裸仓库。PublicSmoke 是唯一默认技术演示，不依赖外部素材；包装依赖、编译和技术渲染与真实影片的字幕校正、代表静帧确认、试听及最终审片分别验收。

分层加载依赖 Agent 按项目规则执行，不是硬性运行时拦截或自动上下文卸载。环境检测是只读检查，不是自动安装器；失败可诊断续接，不使用一次性新 clone 标志。

按 [任务路由](README.md)读取当前步骤，发布能力与已验证结果见 [首发记录](../releases/v0.1.0.md)。未获得真实新机/账号/媒体样本的能力明确待验收，不以历史成功推断当前任务成功。
