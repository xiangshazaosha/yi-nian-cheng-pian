# 按需工作流入口

本页是唯一任务阅读索引，不是全流程必读清单。根 `AGENTS.md` 管常驻边界，技能只指路；参数留在权威文档，不另维护路由配置。

## 如何使用

1. 先确定**动作、片级阶段、已选工具、下一步操作**；明确要求、否定和完成状态优先，不按关键词扩展任务。
2. 只选当前动作入口。执行前完整读取前提、操作、停止条件和验收；小操作包可整页读，长文件按章节并补齐共同约束，不截走例外和闸门。
3. 条件满足才继续：进入下一步、出现对应故障或开始部署/研究。参考链接不自动追读；针对具体问题逐步扩展，不禁止必要的深入排错。
4. 已提供且未变的规则不重复全文加载。已读不等于已执行；交付看实际证据。本页不是权限隔离或自动加载器。

## 共同边界

- 历史按具体问题查，不覆盖当前项目与实际环境；正常操作不自动读部署/选型/实测历史。
- 输出截断须补齐当前操作所需内容。全片规划顺序读完整字幕，局部修复只读当前语义窗与相邻句。
- 通用技能须核对适用环境，不用其他产品步骤/参数替换本项目路径；索引不能阻止上层技能注入，不私改全局技能。
- 统计回传结论和证据路径，完整日志/JSON/包元信息仅排错时展开；不以“已读”代替完成证据，不另造状态协议。
- 阶段结束后沿用当前片记录，不再加载旧细节；会话内容不会自动卸载，不承诺零消耗或硬性拦截。
