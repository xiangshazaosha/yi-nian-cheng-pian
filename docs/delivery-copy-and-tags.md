# 发布资料：最小规则

1. **触发**：仅用户明确提出“发布资料”时制作整套；单独要求封面时只制作封面，不自动附加 DOCX。成片完成不自动触发。每个 `<片名>-<风格名>` 单独制作。
2. **依据**：读取该风格最终 MP4、项目登记与校正字幕，核对实际内容和 CTA；不得只凭片名或策划稿编写。
3. **产物**：在 `deliverables/final-videos/<片名>-<风格名>/` 平铺 `<片名>-<风格名>-封面-3x4.png`（`1080×1440`）、`<片名>-<风格名>-封面-4x3.png`（`1440×1080`）和《发布资料.docx》；两个比例针对阅读顺序、人物位置与信息层级分别排版，禁止先做一张再机械裁切另一张；默认两种比例同时验收交付，只有用户明确只要单一比例时例外。封面**不写入 DOCX**。DOCX 只写一份所有平台通用的**发布标题、发布配文、话题标签**。
4. **配文与标签**：发布配文正文最多 **50 个可见字符**，标点、空格和英文字符计入，单列话题标签不计入。每个标签须有片中依据，并在抖音站内核对同名话题及相关性；所有平台原样使用这一组标签，不声称它们在其他平台也有同名话题。不能核验则标签栏标“待核验”，不凑无关热词或保证流量。
5. **交付**：已有合格封面可复用，但须归一为上述文件名，不留旧名副本；缺少可靠内容依据时停止编造并说明缺口。未收到“发布资料”请求时，缺封面或 DOCX 不影响成片阶段完成。

供**上传发布 agent** 取用文件和文字的统一标准见 `docs/publishing-materials-agent-interface.md`。
