# 音效来源核查与准备

公开版本没有附送音效，也不提供“所有平台音效都免费商用”的保证。请为当前实际选用的每一项记录来源页面、作者、适用许可、获取日期及允许的修改/商用/再分发范围；平台首页或可下载 URL 不等于具体文件许可。

按 [音效规则](sfx-rules.md)选择短促、不抢口播且语义匹配的声音；静默、音效预设缺失和未启用属于不同状态，不为了补齐默认库而盲目下载。

需要自行准备时先取得下载/使用授权，保留原许可和来源。授权不明确的素材不进入发行包；用户本机可用也不意味着仓库可以再分发。将已核验素材登记到空白资产索引，按 [入库规则](user-sfx-assets.md)处理。

完成后在当前片的实际预览中验证播放、峰值、口播余量及听感；文件存在或波形测量不等于听审通过。不会为这一检查重装工具或渲染整片。
