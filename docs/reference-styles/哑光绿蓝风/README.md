## 配方

- 原奶白包装背景替换为哑光中深绿 `#284B40`；纯色、无辉光、无金属渐变。
- 原黄色文字、指示线、头像边线替换为浅蓝 `#A9D7F2`。正文为偏冷白 `#F0F4F1`，次文字为灰绿 `#B7CEC5`；图示表面为 `#335B4D`。
- 素材本身不染色：人物皮肤、真实墙面、软件原生颜色、效果图、黑色录屏底保留。只有设计层改色；独立解释页使用完整绿底。
- 原圆形头像改为16px微圆角正方形、2px浅蓝细边，无额外阴影或光晕。
- 面积按画布既有实际头像计算：常规直径210px、照片段204px；新圆角正方形面积是旧圆形面积的3倍。公式 `side = sqrt(3π(d/2)² + (4−π)r²)`；常规边长约323px、照片段约314px，不是边长乘3。

## 黑底跟随素材（继承双色风规则，优先于绿色配方）

来源：`docs/reference-styles/双色类/AI干进专业工作-阶段1-风格归档.md` 的“黑底与暖白切换”“头像与黑帧处理”，及 `docs/04-design-log.md` 的 LESSON-023 和有效 B-roll 空窗处理经验。

- B-roll 有大面积黑色时，整个外部包装画布、字幕安全带和视频容器底色必须跟随素材的同一种黑色，不能保留绿色侧栏或绿边；不能一律用预设 `#050505` 代替源黑。
- 在原分辨率素材中取样大面积平坦背景，排除文字、照片、控件和压缩边缘，登记每段色值。同段稳定使用同一值，不逐帧自动变色造成闪烁。
- 当前静帧实际取样：24秒 / 81秒为 `#060606`；30秒 / 98秒为 `#000000`；140秒为 `#000000`。黑底页保留白字和浅蓝强调、微圆角方头像。
- 无 B-roll 的独立包装页才使用哑光绿；夹在两段黑底 B-roll 之间的短空窗继续同色黑底，避免突然闪绿。120.5秒的独立解释页保持绿底。
- 在明确操作、点击或结果反馈完成后的语义边界切换整页底色；背景、目录和文字对比度同步切换，不用半透明或局部上推的绿色层长期压住 B-roll，不加随机白点和无关辉光。
- 素材自身不染色、不为改底色重做既有蒙版；源画面黑帧不得用无关人物补口型。有效头像结束前下沉淡出，由同语义图形接管；源画面恢复后反向升起淡入。动态行为须后续单独验证。

取样需经过实际渲染色彩管理复核：当前源PNG带gamma=0.50994，原始RGB18在Chromium输出为RGB6，原始RGB2输出为RGB0。以上配方记录的是最终呈现的匹配值，而非直接照搬原始像素；不改变源素材颜色。
