# 红蓝几何动画风

> **状态：用户已选定视觉风格；《token自由点将台》完整时间轴、字幕、动态与正式成片已完成技术/视觉验收，等待用户审片。**  
> 触发词：**红蓝几何动画风 / 红蓝几何风 / 红蓝·几何动画风**。仅说“几何风”而无明确上下文时不自动等同于本风格。  
> 主风格：具名的混合叙事风格，以几何角色和图解承担解释，真人保留口播连接，真实 UI 承担操作证据。  
> 公共前置：[跨风格公共规则](../common-rules.md)；返回[风格索引](../README.md)；复用机制见[包装库](../../packaging-library/README.md)。

## 1. 一句话定义

**奶油色平面画布 + 珊瑚红 / 钴蓝角色与重点 + 深蓝粗轮廓，用简单几何角色和明确动作讲清决策、执行、拆分与汇合。**

这不是科技风，也不是双色风或蓝绿风的换色版本。识别核心是角色与图形承担信息职责，而不是把所有文字套进红蓝卡片。不得引入霓虹、HUD、星空、金属 3D、玻璃面板或数字雨。

## 3. 视觉规则表（1920×1080 基准）

| 项目 | 规则 / 基准 | 使用边界 |
| --- | --- | --- |
| 主画布 | 奶油色 `#F5F1E7` | 平整纯色，不加纸纹、粉笔纹理或金属渐变 |
| 主文字 / 结构线 | 深蓝墨色 `#242440` | 标题、轮廓、主要箭头；不用纯黑制造另一套系统 |
| 重点红 | 珊瑚红 `#E75C43` | 关键角色、当前判断、需要突出的一项；不是默认“错误” |
| 结构蓝 | 钴蓝 `#3D55B4` | 执行角色、常规比较对象、结构性标签；不是科技辉光 |
| 辅助黄 | `#F3CE49` | 少量角色细节或类别区分，不变成第三个大面积背景 |
| 次文字 | 灰紫 `#686777` | 单位、来源、辅助说明；承担主要信息时必须保证字号与对比度 |
| 字体 | `Noto Sans SC`，回退 `Microsoft YaHei`，再回退无衬线 | 中文粗黑体与清晰数字；不混用书法、楷体、衬线杂志标题 |
| 标题 | 样张 73–98px，常用粗字重 800–850，最多两行 | 按内容调节，不为凑两行拆断术语；主标题只表达当前主要判断 |
| 角色 / 步骤标签 | 约 40–58px，中粗至粗体 | 贴近所指对象，不能被路径穿过 |
| 眉题 / 解释 | 约 25–31px；来源说明样张 20px | 关键事实不能降成脚注；最终需缩略图检查 |
| 大数字 | 样张 112–132px | 单位明确，使用真实数据，不能把装饰数字当事实 |
| 角色描边 | 约 6–8px，深蓝墨色 | 平面实线、无外发光；小图形按尺寸适当减细 |
| 关系线 | 约 6–8px，实线路径和明确箭头 | 只画当前需要解释的关系，连线不得穿字 |
| UI 容器 | 样张圆角 26px、深蓝 5px 边，白色原界面 | 对象本身是截图才使用容器；不把一切信息变成面板 |
| 阴影 / 立体 | 默认无阴影、无透视、无玻璃 | 保持平面图解的直接性，不移植其他风格的材质 |

颜色职责在同一个关系图内保持一致；跨章节可以按语义重新分配，但必须由标签解释，不能让观众猜红蓝含义。图表可用红色突出当前比较项、蓝色作为参照，不能把“红色 = 旗舰”机械套进所有数据页。

独立令牌源已建立于 `remotion-clone/src/styles/red-blue-geometry.ts`；实际片级实现位于 `remotion-clone/src/token-command/`。已确认样张保留，不改 `lib/theme.ts`、双色风或蓝绿风的全局默认值。

## 4. 几何角色与装饰

- 圆、方、圆角方等形状可以承担不同角色，允许最少量眼睛、嘴和身份细节，但角色必须有文字标签，不能只凭表情传达专业关系。
- 角色数量由当段任务决定；重复角色表示同类执行者，形状差异若表达类别必须有一致含义。
- 样张皇冠表示“决策角色”，不是证明某个模型在全部指标领先，也不是要求每个主脑永久戴皇冠。
- 人物是原口播实拍，不进行生成式换脸、卡通化或重新配口型。
- 大圆、半圆、圆弧仅用于构图平衡。默认不超过两个边缘装饰，退出字幕、数据标签、UI 与人物安全区；无用时可以完全不用。
- 不做无意义眼睛乱转、持续蹦跳或“每出现一个数字就表演一次”。角色为解释服务，不能抢口播。

## 5. 语义任务 × 使用环境

| 语义任务 | 环境与画面职责 | 构图与递进 |
| --- | --- | --- |
| 建立观点 / 段首重音 | 真人或独立包装页，先让观众抓住判断 | 一个大标题、一个重点；图形不能提前泄露后文 |
| 主脑决策 / 执行分工 | 解释页，区分职责并显示任务去向 | 主角色先出现，执行对象按口播建立，路径连接，最后强调分工结果 |
| 比较成本 / 能力 | 数据页，读出差异与条件 | 统一刻度、直接数字标签、红色当前项、蓝色参照；来源和条件保留，不强加角色 |
| 设置 / 点击 / 填写 | 真实 B-roll，重点是实际控件 | 左侧简短步骤、右侧真实界面或全屏源界面；必要时按完整 ROI 推近，头像放框外留白 |
| 跨 Agent 派发 / 回传 | 关系图，区分发出、执行和返回 | 真实工具名称标明对象身份；一条主要运动路径逐步展示，不同时堆满双向箭头 |
| 总结 / CTA | 回到真人或精简包装页 | 只保留当时已说到的结论、分享对象与动作，避免把全片大纲挤成一页 |

## 6. 真人、UI、字幕与安全区

### 真人

- 默认使用实拍圆头像，深蓝墨色实线边、无辉光。样张解释页约 410px、操作页约 156px，描边均约 6px；这是两种密度下的参考，不是统一尺寸。
- 解释页头像可稍大，操作页须让位于控件。位置由布局决定，不强制左下，也不继承蓝绿风的三倍面积方头像。
- 已确认数据样张没有头像，因此不强制给每张数据页补头像；若当前片后续明确要求全程头像，则按该要求适配并重新检查安全区。
- 真人全屏页保持源背景，不套粗圆框，不给皮肤或墙面染红蓝。全屏与头像的连续转场可复用共享机制，但替换边框外观并核对同源同帧。

### UI / 证据

- 保留原始软件配色、字段、模型版本与输入值；红蓝只属于外部包装和定位标记，不重新设计一套假 UI。
- 独立解释页用奶油底，真实黑底软件可以保留黑底或扩展同色画布，不为“统一奶油色”洗白源界面。
- ROI 与安全区先于放大倍率。CC Switch 样张 ROI 为 `(55,800,1210,135)`，只适用于该张 2560×1380 素材；不能固化给其他截图。
- 样张只验证了推近后的静态构图；正式运镜必须另外检查入口、中段、到达、保持、退出。

### 字幕

- 严格继承公共字幕规则：校正版时间轴、逐字同步、默认裸排、无卡片底板。
- 奶油页可用深蓝墨色字，深色源画面用高对比浅字；必要时使用克制字形描边 / 投影，不套角色粗轮廓、彩色圆角气泡或说明卡。
- 样张无 subtitle 层。正式字幕的字号、行高、底部区域需结合校正版字幕和画面重新定标，不能把样张页脚当作字幕样式。
- 1920×1080 默认先留出约 72px 外边距和底部字幕带，再为头像、数据脚注与 UI 分配空间；不要把样张里任一绝对坐标当永久安全区。

## 7. 动效与音效（制作起始建议，尚未动态验收）

已确认的是平面视觉语言，不是下面每一个帧数。正式制作使用帧驱动，不能声称样张已验证这些运动。

| 行为 | 建议起点（30fps） | 禁止 / 验收要点 |
| --- | --- | --- |
| 标题进入 | 10–14 帧，短距离 16–28px 或遮罩揭示 | 不逐字乱跳、不旋转整句，不抢过口播语义 |
| 角色出现 / 接收任务 | 10–16 帧，最多一次轻微落位；缩放可从 0.94 到 1 | 如使用弹性，超过 1 的过冲不大于约 3%，不持续摇摆 |
| 关系建立 | 12–24 帧绘出单一路径 | 节点先有，线和移动任务共用路径与进度，箭头到达后落定 |
| 图表展开 | 14–24 帧同一尺度展开，主数据稳定后给比较强调 | 数字与图形始终一致，不能用夸张缩放伪造差距 |
| 构图切换 | 优先语义切换或 8–12 帧干净交接 | 不默认全片黑场、霓虹扫光或 3D 翻转 |
| 操作放大 | 由目标可读性和操作停留决定 | 缩放和平移共享进度，整段 ROI 安全，不为了节奏裁掉字段 |

音效继续遵守[公共音效规则](../../packaging-library/sfx-rules.md)：先登记动作，再选择声音；同类行为规则一致，并在有人声的事件窗口相对口播校准。风格可选短、干净、轻巧的触感音色，但本次没有新增或批准具体音效素材。`DIGITAL_SWEEP` 等名称是动作分类，不要求本风格发出科幻电子声；普通字幕和装饰不加声。BGM 不因风格归档自动开启。

## 8. 公共规则继承 / 外观覆盖表

| 既有规则或历史默认 | 本风格处理 |
| --- | --- |
| 字幕校对、分层、裸排；真实素材；固定源偏移；主音轨；ROI；几何单一真源；分段与交付 | **全部继承**，不以风格为理由例外 |
| 动效使用 Remotion 帧驱动、同动作同音效规则、相对口播校准 | **继承机制**，本风格另定动幅、节奏和音色 |
| 双色风的黄为唯一常规强调色、黄色头像细边 | **不继承外观**；改用本风格红蓝职责与深蓝实线头像边 |
| 蓝绿风的三倍面积方头像与蓝绿配色 | **不继承**；圆头像随信息密度调节 |
| 秋芝风的紫框、辉光、星空、统一暗角、强弹跳 | **不适用**，禁用这些默认皮肤 |
| 历史 CaptionBar 的字幕底板 | **不适用**；服从项目裸排字幕硬规则 |
| 所有 B-roll 固定左下头像 / 固定 78% UI 框 | **不固定套用**；真实 UI 可读性与当前片的明确要求优先 |
| 历史文件卡透视、重阴影、持续漂移、黑场交接 | **不自动继承**；采用本风格平面结构和语义交接 |

## 9. 禁用项与验收

- 禁止科技皮肤、纸片拼贴、实体棋子 / 木质 3D、粉笔字等其他风格配方混入。
- 禁止整段都套同一种图解、角色数量机械固定、角色表演掩盖关键操作。
- 禁止标题与图表同时争夺第一视觉重点，禁止连线穿文字，禁止装饰挤入字幕或截图重点。
- 检查原图和缩略观看两种尺度下的文字、数字、单位、人物裁切与界面可读性。
- 图表必须检查原始数据和尺度；UI 必须检查原始 ROI；字幕必须检查权威时间轴。
- 动态验收覆盖入口、中段、到达、保持、退出与段间交接；仍未完成的项如实标注，不以静帧通过替代。
- 同片不同风格正式交付不覆盖；本风格将来使用稳定名称“红蓝几何动画风”，《token自由点将台》已有该风格正式成片，路径见单片交付登记。

## 10. 归档与复用边界

这是新建的独立风格配方，不是新建一批通用组件。本次不修改组件 API，不改编辑器注册或公共 `theme.ts`，包装库分类计数不变。未来若提炼几何角色组件或新的关系图 API，再单独按包装库三维判定与测试流程执行。
