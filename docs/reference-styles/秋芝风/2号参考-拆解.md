# 参考视频补充拆解：2号参考.mp4

> 视频源：`参考视频/2号参考.mp4`  
> 主风格：**秋芝风**  
> 与基线关系：同系列扩展，不建立新风格。

## 风格判定

本片延续 `秋芝.mp4` 的暗色星空、紫色圆形头像、底部字幕、圆角 UI 框和高饱和强调色。主要变化来自承载 UI 的设备样机和交互指针，因此归入秋芝风，而不是另建屏幕演示类。

## 语义任务 × 使用环境

| 语义任务 | 触发语义 | 使用环境 | 画面职责与推荐组合 |
| --- | --- | --- | --- |
| 手机操作演示 | App、微信、竖屏界面、移动端步骤 | 原界面为竖屏，直接放大容易产生大面积空白 | `RoundedUIFrame variant="phone"` 建立手机语境，头像留在框外，指针只指当前操作 |
| 网页或 AI 助手演示 | 打开网页、输入提示、选择功能、查看生成结果 | 横向网页、对话框、表单或浏览器操作 | `variant="web"` 用顶栏和地址栏说明载体，`CursorPointer` 按口播移动到目标 |
| 合同 / 表格 / 文档证据 | 查看合同、表格、清单、报告 | 内容需要被当作文件阅读，而不是软件操作 | `variant="document"` 使用白底、细灰边和小圆角；避免浏览器顶栏抢占正文空间 |
| 点击位置强调 | “点击这里”“选择这个”“输入到这里” | 目标按钮不够醒目，但需要保持原界面完整 | 橙色手型指针移动到目标后 pulse 两次；指尖坐标与目标框使用同一坐标系 |
| 案例角色或情绪补充 | 轻量案例、角色对话、趣味化解释 | 信息不复杂，需要短暂降低技术感 | 可使用 3D 吉祥物对，但它依赖外部素材且复用率低，不能成为必要组件 |

## 新增视觉模块

### 1. 设备样机框

- **phone**：深色边框、顶部刘海、圆角屏幕；适合竖屏 App 和聊天界面。
- **web**：浏览器顶栏、红黄绿三圆点、地址栏；适合网页和 AI 助手。
- **document**：白底、细灰边、小圆角；适合合同、表格和文档。
- 三种样机都属于 `RoundedUIFrame` 的载体变体，不应复制成三个独立风格组件。

### 2. CursorPointer

- 橙色手型指针，指尖是对齐热点。
- 移动使用 ease-in-out，到达后 pulse 两次。
- 适合真实操作指向，不适合纯观点卡或无需点击的结果展示。
- 指针、目标框和点击波纹必须共享同一坐标系。

### 3. 3D 吉祥物对

- 只在少数案例段出现，属于内容资产而非基础视觉机制。
- 无匹配素材时直接不用，不需要为保持秋芝风强行生成。

## 与现有包装库的对应关系

- 设备样机已作为 `RoundedUIFrame` 的 `plain / phone / web / document` variants 实现。
- 交互指针已作为 `CursorPointer` 实现。
- 3D 吉祥物未实现，等待实际素材需求。

## 关键参数

- phone：边框 padding 3.5%，大圆角 12%，屏幕圆角 8%，刘海宽 22%、高 3.5%。
- web：顶栏高约 6%，小尺寸至少 36px；地址栏宽约 60%。
- document：白底 `#FFFFFF`、1px `#D0D0D0`、圆角 6px。
- CursorPointer：SVG viewBox 40×56，指尖 `(20, 50)`，默认尺寸 64，移动约 10 帧，pulse 周期约 14 帧、两次。

这些数值是秋芝风预设，不妨碍底层组件跨风格复用；其他风格使用同一组件时应覆盖颜色、动幅、圆角、阴影和强调频率。
