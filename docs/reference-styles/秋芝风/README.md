# 秋芝风

> 两条同系列参考视频的风格总档。先读本页确定视觉语言，再按需要读取具体拆解。

## 参考来源

- [`秋芝.mp4`](./秋芝-拆解.md)：基线风格，覆盖主播口播、标题页、圆角 UI 演示、左右对比、结果展示和完整动效体系。
- [`2号参考.mp4`](./2号参考-拆解.md)：同系列补充，新增手机 / 网页 / 文档样机、交互指针和少量 3D 吉祥物使用环境。

## 风格定义

秋芝风是**真人口播与 UI 演示混合叙事**：主播负责关系、态度和结论，录屏 / 截图负责操作和证据，纯文字标题页负责章节与强观点。

核心识别组合：

- 暗色星空或紫灯氛围；
- 紫色渐变描边圆形头像；
- 黄 / 绿 / 橙高饱和标签；
- 圆角 UI 框及手机、网页、文档样机；
- 标题滑入、标签 spring 弹出、顺序揭示、局部高亮和光标指向；
- 底部口播字幕维持叙事连续性。

只复用其中一个孤立组件不等于采用秋芝风。目标画面需要同时满足“暗色氛围 + 高饱和强调 + 人物 / UI 主次关系”中的至少两项，并使用相符的动效预设。

## 两条视频的关系

`2号参考.mp4` 不是另一种风格，而是秋芝风在更多 UI 载体上的扩展：

- `秋芝.mp4` 定义基线视觉和叙事组合；
- `2号参考.mp4` 补足 phone / web / document 三类设备样机和 `CursorPointer`；
- 两者共享圆角、头像、标签、字幕和动效语言，应该归在同一风格下；
- 3D 吉祥物依赖外部素材且复用率低，只作为可选内容资产，不作为风格硬条件。

## 动效能否跨风格共用

**动效机制可以共用，但动效预设会影响风格。** 分三层处理：

| 层级 | 是否共用 | 说明 |
| --- | --- | --- |
| 动效引擎 | 可以 | `interpolate`、`spring`、淡入、位移、缩放、线条绘制、光标路径等实现代码可共享 |
| 动效预设 | 按风格隔离 | 时长、位移幅度、overshoot、缓动、颜色、辉光和音效决定动作气质 |
| 动效组合与频率 | 按风格隔离 | 同时弹几张卡、是否跟口播重音、主转场类型和重复频率都会改变风格 |

### 秋芝风动效预设

- 标签 / 卡片允许明显 spring overshoot，强调“弹出感”；
- 标题常从左侧或下方短距离滑入，并配合淡入；
- 黄绿橙色、紫色描边和外发光与动作绑定；
- 演示段允许光标移动、点击 pulse、高亮框脉冲；
- 多项内容跟随口播重音逐项出现，不一次铺满。

### 跨风格复用边界

- 可把同一个 `spring-scale-enter` 函数用于纯文案类，但纯文案类应换成更克制的参数，减少 overshoot、位移和辉光。
- 可共享淡入、顺序揭示、线条生长等机制，但颜色、速度和组合密度从目标风格读取。
- 秋芝风的紫色头像、霓虹标签、星空背景不是“动效”，不得因复用动画组件而自动带入其他风格。
- 反过来，纯文案类的皇家蓝斜切主转场也不能自动成为秋芝风默认转场。

## 使用触发词

用户说以下任一表达时读取本目录：

- `秋芝风`
- `秋芝风格`
- `按秋芝那套做`

成片规划默认读取本页和所需详细拆解，不读取其他风格的视觉预设；共享动效只复用实现机制。
