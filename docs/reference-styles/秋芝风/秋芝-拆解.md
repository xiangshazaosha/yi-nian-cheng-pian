# 参考视频拆解：秋芝.mp4

> 阶段一输出。2026-07-20 完成首次拆解，现归档到“秋芝风”。
> 视频源：`参考视频/秋芝.mp4`

## 风格身份证

- **主风格**：秋芝风
- **次要特征**：真人口播 + UI 演示混合叙事、AI 工具测评 / 教程包装
- **核心识别**：暗色星空或紫灯氛围、紫色圆形头像、高饱和黄绿橙标签、圆角 UI 框、spring 弹出和关键词强调
- **风格边界**：允许人物与录屏交替承担主叙事；不等同于纯文案类的报告排版，也不等同于无包装的连续录屏

## 语义任务 × 使用环境

| 语义任务 | 触发语义 | 使用环境 | 画面职责与推荐组合 |
| --- | --- | --- | --- |
| 主播建立关系 | 开场、态度、经验、结论、CTA | 需要人物可信度和情绪感染的教程 / 测评 | 主播全屏或居中，底部字幕常驻，右上只放 1-2 个高饱和标签 |
| 概念或章节强调 | 新章节、核心卖点、情绪转折 | 需要短暂停顿，让观众先记住一句话 | 人物退场，全屏大标题配暗色星空；标题滑入，副标题延迟淡入 |
| 软件操作演示 | “打开”“点击”“输入”“生成”等操作语义 | App、网页、AI 工具和表单教程 | 圆角 UI 框承担主体，左下紫色圆形头像保留人物连续性，光标 / 高亮框只指向当前操作 |
| 功能与步骤枚举 | 多个卖点、步骤、注意事项 | 口播按条列举，信息需要逐项消化 | 主播或录屏常驻，黄绿橙标签 / 步骤卡按重音逐张 spring 弹出 |
| 对比与选择 | A/B、旧方案/新方案、优点/缺点 | 工具比较、概念区分、方案决策 | 左右圆角分屏，顶部标签先区分类别，bullet 再逐条出现 |
| 结果与案例证明 | “最后得到”“效果如下”“案例是” | 产品结果、生成物、文件或数据展示 | 主结果卡优先，主播缩小让位；高亮框和标注线只强化一个证据点 |
| 痛点密集铺陈 | 多个焦虑词、常见问题、失败原因 | 开场铺垫或从问题转入解决方案 | 可用关键词云或多标签快速出现，但只用于扫读，不承载需精读的信息 |

同一语义场景按内容调用，不按原片时间顺序复刻。动画的帧数和时机属于实现参数，原片时码只用于定位证据。

## 一、主构图模式库

### 1. 主播居中口播构图
- 人物位置：画面水平居中，垂直居中偏下；人物占画面宽度约 35-50%，高度约 55-70%，胸像/半身。
- 信息区：口播字幕位于画面底部 85-92% 处；强调标签常置于右上角（距顶 8-12%，距右 5-10%）。
- 适合承载：开场、结论、情感强调、CTA。
- 信息容量上限：1-2 个关键词标签 + 1 行字幕。
- 不适合：需要展示大量 UI 或数据的场景。
- 人物状态：自然手势，无大尺度移动，偶尔配合语言做手势。

### 2. 全屏标题/概念卡构图
- 人物位置：无人物，纯图形文字。
- 信息区：大标题居中或偏左，覆盖画面 30-70% 宽度；副标题或说明文字位于主标题下方 10-15%。
- 适合承载：章节标题、核心观点、一句话卖点、情绪转折。
- 信息容量上限：1 个大标题 + 1 行小字。
- 不适合：长时间停留，通常 2-4 秒。
- 人物状态：无需人物。

### 3. 圆角 UI 录屏主构图
- 人物位置：主播以圆形头像形式出现在左下角，直径约 12-15% 画面宽度。
- 信息区：UI 界面以圆角矩形占据画面 85-95%，圆角约 24-36px；顶部中央常有橙底黑字标题标签。
- 适合承载：软件操作演示、功能介绍、结果展示。
- 信息容量上限：完整 App 界面 + 1-2 个高亮标注。
- 不适合：需要主播强烈情绪表达的场景。
- 人物状态：圆形头像静态或轻微眨眼/点头。

### 4. 左右分屏对比构图
- 人物位置：主播圆形头像仍在左下角；主画面左右各一圆角卡片，各占 45-48% 宽度，中间留 2-4% 间隙。
- 信息区：左侧为本地 Agent 界面，右侧为对话型 AI 界面；顶部两侧各一标签。
- 适合承载：对比、优劣分析、概念区分。
- 信息容量上限：两侧各 1 个主标题 + 3-4 个 bullet。
- 不适合：单一概念讲解。
- 人物状态：头像常驻。

### 5. 人物左/右 + 信息卡构图
- 人物位置：主播占据画面左侧或右侧约 40-45% 宽度，其余区域放信息卡/截图。
- 信息区：右侧或左侧放置 1-2 张大图/卡片，带圆角和轻微阴影。
- 适合承载：介绍人物 + 展示产物/案例。
- 信息容量上限：主播画面 + 1 张主图 + 1-2 行说明。
- 不适合：需要主播和大量文字并存的场景。
- 人物状态：主播面向信息区方向，做引导手势。

### 6. 全屏关键词云/弹幕构图
- 人物位置：无人物或仅极小头像。
- 信息区：多个关键词以不同角度、大小漂浮在画面中央，形成视觉冲击力。
- 适合承载：痛点罗列、概念密集出现、情绪铺垫。
- 信息容量上限：8-15 个关键词。
- 不适合：信息需要精读的场景。
- 人物状态：无。

## 二、内容组件库

### 1. 大标题
- 位置：画面中央或偏上 20-35%。
- 字体与层级：粗体无衬线，白色 #FFFFFF，字号约占画面高度 12-20%。
- 单次信息量：1 句 4-8 字。
- 可同现：副标题、小标签、底部字幕。
- 不宜同现：多个同级别大标题、复杂图表。
- 动效：从下方滑入 + 淡入，持续 12-18 帧；退出时向上淡出。

### 2. 副标题/一句话摘要
- 位置：主标题下方 8-12%。
- 字体与层级：常规无衬线，#B0B0B0 或 #FFFFFF，字号为大标题 30-40%。
- 单次信息量：1 行 10-20 字。
- 可同现：大标题、按钮、图标。
- 不宜同现：过多 bullet。
- 动效：比主标题延迟 3-6 帧淡入。

### 3. 事实卡/观点卡
- 位置：右上角或画面右侧中部。
- 字体与层级：黄底 #FFE600 或绿底 #CCFF00 圆角矩形，黑字 #000000，圆角半径 12-20px。
- 单次信息量：1 个编号 + 6-10 字。
- 可同现：主播画面、底部字幕。
- 不宜同现：同屏超过 3 张。
- 动效：缩放 0.8->1.0 + 透明度，带轻微 overshoot，持续 10-15 帧。

### 4. 步骤卡/数字卡
- 位置：画面右侧竖向排列或底部横向排列。
- 字体与层级：编号圆圈 + 黄/绿底色条，黑字。
- 单次信息量：3-5 个步骤。
- 可同现：主播画面。
- 不宜同现：复杂 UI 截图。
- 动效：逐张出现，每张间隔 10-15 帧。

### 5. 对比卡
- 位置：左右分屏，各占 45-48%。
- 字体与层级：顶部标签区分左右，内容用白色标题 + 灰色正文。
- 单次信息量：两侧各 3-4 个 bullet。
- 可同现：顶部标签、高亮箭头。
- 不宜同现：底部字幕过长。
- 动效：两侧同时滑入，或先左后右。

### 6. 图表/流程图
- 位置：画面中央或右侧信息区。
- 字体与层级：浅色背景卡片 + 深色文字，流程节点用圆角矩形连接。
- 单次信息量：3-5 个节点。
- 可同现：主播画面、标题标签。
- 不宜同现：过多文字堆叠。
- 动效：节点依次放大出现，连线生长。

### 7. 截图/屏幕录制
- 位置：占据画面 85-95%，圆角 24-36px。
- 字体与层级：保留原 UI 文字，顶部叠加橙底标题标签。
- 单次信息量：1 个完整界面。
- 可同现：圆形主播头像、鼠标光标轨迹、高亮框。
- 不宜同现：大面积遮挡文字的元素。
- 动效：淡入 + 轻微放大，光标按路径移动。

### 8. 图标组合
- 位置：标题左侧或卡片内。
- 字体与层级：线性或面性图标，白色或品牌色。
- 单次信息量：1-4 个图标。
- 可同现：标题、说明文字。
- 不宜同现：过多装饰图标。
- 动效：依次弹出。

### 9. 关键词强调
- 位置：画面中央或跟随讲解位置。
- 字体与层级：黄底 #FFE600 或绿底 #CCFF00 文字，黑字，字号较大。
- 单次信息量：1-3 个关键词。
- 可同现：屏幕录制、主播画面。
- 不宜同现：多个同时高亮。
- 动效：放大 1.1-1.3 倍 + 底色闪烁，持续 15-30 帧。

### 10. 口播字幕
- 位置：画面底部 85-92%，水平居中。
- 字体与层级：黑底半透明 #000000 80% 透明度，白字 #FFFFFF，圆角条。
- 单次信息量：1-2 行，每行 8-15 字。
- 可同现：所有构图。
- 不宜同现：无。
- 动效：逐字或逐句淡入。

> 注：本项目口播原片底部字幕已烧入视频，Remotion 不重做。本组件库中的"口播字幕"仅用于描述参考视频的视觉规则，不作为本项目实现项。

## 三、视觉处理模块库

### 1. 暗色星空背景
- 作用对象：全局背景层。
- 图层顺序：最底层。
- 使用位置：标题卡、对比卡、全屏概念画面。
- 参数：背景色 #050505，星星为白色小点，密度约 30-50 颗/帧，透明度 0.3-0.6，轻微闪烁。

### 2. 主播背景虚化/紫灯氛围
- 作用对象：主播原始素材背景。
- 图层顺序：人物层下方。
- 使用位置：主播口播段。
- 参数：背景为真实紫灯棚，已有浅景深；若合成需添加暗角，四角 #000000 透明度 20-40%。

### 3. 圆角裁切（UI 框）
- 作用对象：屏幕录制/截图。
- 图层顺序：中上层。
- 使用位置：演示段。
- 参数：圆角 24-36px，外框 2-4px #E0E0E0 或 #FFFFFF30，轻微阴影 y 8-16px blur 24px #00000060。

### 4. 圆形头像蒙版
- 作用对象：主播画面。
- 图层顺序：屏幕录制层上方。
- 使用位置：演示段。
- 参数：圆形直径 12-15% 画面宽度，紫色渐变描边 #A020F0->#FF00FF，描边 3-5px，阴影 y 4px blur 12px #00000050。

### 5. 高饱和标签
- 作用对象：强调文字/编号。
- 图层顺序：内容层上方。
- 使用位置：口播段右上角、演示段顶部、关键词强调。
- 参数：黄 #FFE600 / 绿 #CCFF00 / 橙 #FF6600，黑字，圆角 12-20px，内边距 8-16px。

### 6. 局部放大/高亮框
- 作用对象：屏幕录制中的关键按钮/区域。
- 图层顺序：录屏层上方。
- 使用位置：演示重点。
- 参数：圆角矩形描边 2-3px #FFE600，背景遮罩 #00000040，放大比例 1.05-1.15。

### 7. 暗角/聚光
- 作用对象：全屏。
- 图层顺序：最上层（低透明度）。
- 使用位置：情绪强调、开场。
- 参数：径向渐变，中心透明，边缘 #000000 透明度 30-60%。

### 8. 半透明信息条
- 作用对象：底部字幕、说明条。
- 图层顺序：人物/内容层上方。
- 使用位置：所有带字幕段落。
- 参数：背景 #000000 70-85% 透明度，圆角 8-16px。

## 四、动效与转场模块库

### 1. 标题滑入
- 作用对象：大标题、副标题。
- 开始时机：段落开始或切换后 0-6 帧。
- 持续时间：12-18 帧（0.4-0.6s）。
- 方向：从下方 30-50px 滑入。
- 缓动：ease-out / cubic-bezier(0.16, 1, 0.3, 1)。
- 与语音同步：常在句首重音处完成出现。
- 可组合：淡入、轻微缩放。
- 高频复用：是。

### 2. 标签弹出
- 作用对象：强调标签、步骤编号。
- 开始时机：讲到对应要点时。
- 持续时间：10-15 帧。
- 方向：从中心缩放。
- 缓动：overshoot / back-out。
- 与语音同步：与关键词发音同步。
- 可组合：透明度、旋转 ±5°。
- 高频复用：是。

### 3. 关键词放大
- 作用对象：单个词语或短语。
- 开始时机：语音重音。
- 持续时间：15-30 帧。
- 方向：中心放大 1.1-1.3 倍。
- 缓动：ease-in-out。
- 与语音同步：是。
- 可组合：底色闪烁、描边。
- 高频复用：是。

### 4. 录屏框淡入放大
- 作用对象：UI 截图/录屏。
- 开始时机：进入演示段落。
- 持续时间：18-24 帧。
- 方向：从 0.95->1.0 放大 + 透明度 0->1。
- 缓动：ease-out。
- 与语音同步：略早于讲解开始。
- 可组合：圆形头像滑入。
- 高频复用：是。

### 5. 圆形头像滑入
- 作用对象：主播圆形头像。
- 开始时机：录屏框稳定后 6-12 帧。
- 持续时间：12-18 帧。
- 方向：从左下方向内滑入。
- 缓动：ease-out。
- 与语音同步：与讲解同步。
- 可组合：录屏框淡入。
- 高频复用：是。

### 6. 卡片逐张出现
- 作用对象：步骤卡、bullet 卡。
- 开始时机：逐条讲解时。
- 持续时间：每张 10-15 帧，间隔 8-12 帧。
- 方向：从右侧或下方滑入。
- 缓动：ease-out。
- 与语音同步：是。
- 可组合：标签弹出。
- 高频复用：是。

### 7. 分屏左右展开
- 作用对象：左右对比卡。
- 开始时机：进入对比段落。
- 持续时间：18-24 帧。
- 方向：左右两侧从中线向两侧展开。
- 缓动：ease-out。
- 与语音同步：略早于讲解。
- 可组合：顶部标签落下。
- 高频复用：中。

### 8. 光标轨迹
- 作用对象：录屏中的鼠标指针。
- 开始时机：讲解到操作步骤时。
- 持续时间：根据操作长度 30-90 帧。
- 方向：沿 UI 元素移动。
- 缓动：linear 或 ease-in-out。
- 与语音同步：是。
- 可组合：点击涟漪、高亮框。
- 高频复用：是（演示段）。

### 9. 全屏色块转场
- 作用对象：画面整体。
- 开始时机：大段落切换。
- 持续时间：6-12 帧。
- 方向：黑色或深色全屏闪切/渐变。
- 缓动：linear。
- 与语音同步：常在停顿处。
- 可组合：无。
- 高频复用：中。

### 10. 模糊转清晰
- 作用对象：背景或次要信息。
- 开始时机：需要聚焦某一元素时。
- 持续时间：12-18 帧。
- 方向：背景 blur 0->8px 再恢复。
- 缓动：ease-in-out。
- 与语音同步：是。
- 可组合：高亮框。
- 高频复用：低。

## 组合方式（5 个典型画面）

### 组合 1：开场钩子
- 主构图：全屏标题/概念卡。
- 内容组件：大标题"0门槛"、底部字幕、关键词云。
- 视觉处理：暗色星空背景、黄色发光文字、径向暗角。
- 动效顺序：背景星星闪烁 -> 大标题滑入 -> 关键词云从四周飞入 -> 切到主播画面。
- 常驻：星空背景。
- 分批：标题先出，关键词后出。

### 组合 2：主播介绍核心卖点
- 主构图：主播居中口播。
- 内容组件：右上角编号标签、底部字幕。
- 视觉处理：紫灯背景、圆形头像无需（主播全身出现）。
- 动效顺序：标签逐张从右侧滑入，每张伴随主播手势。
- 常驻：主播画面、底部字幕。
- 分批：3 个卖点标签依次出现。

### 组合 3：软件功能演示
- 主构图：圆角 UI 录屏主构图。
- 内容组件：UI 界面、圆形主播头像、顶部橙标、光标轨迹。
- 视觉处理：圆角裁切、阴影、紫色头像描边。
- 动效顺序：录屏框淡入放大 -> 圆形头像滑入 -> 光标移动 -> 高亮框出现 -> 结果卡片弹出。
- 常驻：录屏框、圆形头像。
- 分批：操作步骤分批高亮。

### 组合 4：左右对比
- 主构图：左右分屏对比构图。
- 内容组件：两侧 UI 截图、顶部标签、bullet 列表。

## 建议的可复用组件（RECOMMENDED_CHANGES）

视觉代理建议建立以下 7 个可复用组件：

1. **BackgroundStarfield**：固定随机种子生成约 50 颗白色小点，透明度 0.3-0.6，加入轻微闪烁动画。
2. **HostSpeakingLayout**：主播居中，预留底部字幕位（占高 8-12%）和右上角标签位（占宽 30-40%，置顶 8-12%）。
3. **ScreenDemoLayout**：传入录屏素材用 border-radius: 28px 裁切，加 2px 浅色外框和阴影；左下角固定 14% 圆形主播头像，带紫色渐变描边。
4. **ComparisonLayout**：左右分屏，支持两块独立内容区。
5. **HighlightTag**：三种预设颜色（黄 #FFE600 / 绿 #CCFF00 / 橙 #FF6600），动画为 scale spring 0.8->1.0 + opacity，持续 0.4-0.5s。
6. **CaptionBar**：底部半透明黑底白字圆角条。注：本项目原片已烧入字幕，此组件仅用于补位或全屏图表阶段。
7. **CursorPath**：SVG 组件，用 interpolate 控制光标沿 UI 元素移动，并在点击点加入 0.2s 涟漪。

所有文字进入动画统一使用 Remotion `spring` 或 `interpolate` + `cubic-bezier(0.16, 1, 0.3, 1)`，优先从下方 40px 滑入。

## 总结

**核心特征**：暗色星空底 + 紫灯主播棚 + 高饱和黄绿橙标签 + 圆角 UI 录屏框 + 圆形主播头像，五位一体的强一致性模板。

**最值得复刻的 3 个元素**：
1. 主播口播段固定右上标签 + 底部字幕的模块；
2. 圆角 UI 录屏框 + 左下圆形头像 + 顶部橙标的演示模块；
3. 标题/标签的 spring 弹出 + 关键词放大动效。

**最不值得照搬的 3 个元素**：
1. 真实紫灯棚的物理场景（需要实拍，不可完全参数化复现）；
2. 关键词云漂浮（信息密度低、可读性差、使用场景窄）；
3. 全屏色块闪切转场（对叙事帮助有限，容易显得突兀）。

**替代建议**：不建议复刻真实紫灯棚，建议用纯色/渐变背景 + 暗角替代，降低拍摄依赖。

## 附录：蒙版与视觉处理补充拆解（10 维度）

> 2026-07-20 补充蒙版与视觉处理细项。
> 针对原"三、视觉处理模块库"中拆解不充分的蒙版部分，按 remotion 版拆解提示词第三节 10 个维度逐项分析。

### 1. 人物抠像
- **是否使用**：否。
- **使用位置**：不适用。
- **参数特征**：主播口播段（全身/半身）为紫灯演播室实拍，背景是真实浅景深场景，边缘自然，未见绿幕或 AI 抠像痕迹。演示段左下角圆形头像也来自同一段口播素材的圆形硬边裁剪，头像内部仍能看到紫灯背景，并非单独录制的圆形视频，也未做抠像。
- **实现建议**：本项目无需引入绿幕/AI 抠像模块，演示段直接用圆形硬边 `clip-path: circle()` 裁剪同一段口播素材即可。
- **是否值得做成可复用模块**：否。

### 2. 几何蒙版
- **是否使用**：部分使用。
- **使用位置**：UI 录屏框、顶部标签/按钮/信息卡、TRAE SOLO 图标。
- **参数特征**：除圆形头像外，主要为圆角矩形：UI 录屏框（圆角 24-36px）、顶部标签/按钮/信息卡（圆角 8-16px）、TRAE SOLO 图标为圆角方形。所有几何蒙版边缘均为**硬边**，无羽化。未见多边形、SVG clipPath 或复杂曲线蒙版。
- **实现建议**：CSS `border-radius` 即可覆盖全部需求，不需要 SVG clipPath。
- **是否值得做成可复用模块**：是，建议新增 `RoundedUIFrame`（圆角矩形 + 2-4px #E0E0E0 实线边框 + 柔和黑色投影）。

### 3. 渐变羽化
- **是否使用**：否。
- **使用位置**：不适用。
- **参数特征**：主播人物边缘与背景之间没有渐变羽化融合；信息卡、截图边缘为硬边；UI 框靠投影柔化，而非 `mask-image` / CSS mask / box-shadow 模拟的羽化；圆形头像边缘也是硬边裁剪。
- **实现建议**：本项目不需要实现渐变羽化。如果未来需要柔和过渡，可用 CSS `mask-image: linear-gradient(...)` 或 SVG mask。
- **是否值得做成可复用模块**：否。

### 4. 描边
- **是否使用**：是。
- **使用位置**：UI 录屏框、圆形头像、局部高亮框。
- **参数特征**：
  - UI 录屏框外框：2-4px 实线 #E0E0E0；
  - 圆形头像：3-5px 紫色渐变描边 #A020F0 -> #FF00FF；
  - 局部高亮框：2-3px 实线 #FFE600 或 #FF6600；
  - 标题文字：未观察到明显外描边，主要靠阴影/辉光保证可读性。
- **实现建议**：CSS `border` 或 `box-shadow` 模拟；圆形头像的渐变描边用 `border-image` 或外层 div + `background: linear-gradient` + 内层 div 镂空。
- **是否值得做成可复用模块**：是，作为标签/高亮框/头像的通用参数。

### 5. 阴影
- **是否使用**：是。
- **使用位置**：UI 录屏框、圆形头像、高亮框、白色强调文字、素材展示。
- **参数特征**：
  - UI 录屏框：柔和黑色投影，y 偏移接近 0，模糊半径约 20-40px，透明度 40-60%；
  - 圆形头像：紫色外发光/投影；
  - 高亮框：同色外发光；
  - 白色强调文字（如"上下文统一"）：黑色 `drop-shadow`；
  - 男性讲解员/产品图等素材：轻微底部投影。
- **实现建议**：CSS `box-shadow` 多层叠加（外发光 + 投影）；文字用 `filter: drop-shadow()`。
- **是否值得做成可复用模块**：是，建议把"描边 + 外发光 + 投影"组合作为标签/高亮框的默认视觉配方。

### 6. 辉光
- **是否使用**：是。
- **使用位置**：开场大标题、执行命令标题、圆形头像、高亮框、"新版"橙色标签。
- **参数特征**：
  - 开场"0 门槛"等大字：强烈黄色辉光 + 水平运动模糊 streak；
  - "执行命令"标题：黄色发光字；
  - 圆形头像：渐变描边本身产生紫色辉光；
  - 高亮框：黄/橙色外发光；
  - "新版"橙色标签：轻微发光。
- **实现建议**：多层 `text-shadow` 或 `filter: drop-shadow()` 模拟黄色强辉光；运动模糊 streak 用 CSS `filter: blur()` 方向性模糊或 SVG `feGaussianBlur` + `feOffset`。
- **是否值得做成可复用模块**：是，建议新增 `GlowTitle`（大标题文字 + 多层 text-shadow + 可选运动模糊 streak）。

### 7. 背景虚化
- **是否使用**：否。
- **使用位置**：不适用。
- **参数特征**：除主播紫灯棚真实浅景深外，未观察到其他人工高斯模糊或局部放大时的背景模糊效果。
- **实现建议**：不适用。如未来需要，用 CSS `filter: blur(8px)` 或 Remotion `interpolate` 控制 blur 值。
- **是否值得做成可复用模块**：否。

### 8. 局部放大
- **是否使用**：部分使用。
- **使用位置**：文件/数据展示、关键词标签、标题卡。
- **参数特征**：
  - 展示文件/数据时：橙色圆角高亮框圈选目标区域，框内内容伴随 1.05-1.15 倍缩放；
  - 关键词标签：常用 0.8->1.0 缩放弹入；
  - 标题卡（如"TRAE SOLO / Let's Go"）：尺度变化。
- **实现建议**：Remotion `spring` + `scale` interpolate；高亮框配合 `transform: scale(1.05-1.15)`。
- **是否值得做成可复用模块**：是，建议新增 `HighlightBox`（圆角矩形 + 2-3px 黄/橙实线描边 + 同色外发光 + 框选区域局部放大）。

### 9. 前景遮挡
- **是否使用**：部分使用。
- **使用位置**：底部口播字幕条、漂浮关键词、顶部标题。
- **参数特征**：
  - 底部口播字幕条、漂浮关键词（如龙虾 / Skill / Docker 等）、顶部标题层叠在画面上方；
  - 未见装饰性几何图形或文字飘过式的转场遮挡。
- **实现建议**：CSS `z-index` 层叠；漂浮关键词用 absolute 定位 + Remotion `interpolate` 控制位置。
- **是否值得做成可复用模块**：否，作为常规层叠处理即可。

### 10. 背景纹理
- **是否使用**：部分使用。
- **使用位置**：主背景、男性讲解员/素材展示段、口播段。
- **参数特征**：
  - 主背景：暗色星空点（已拆解）；
  - 男性讲解员/素材展示段：浅灰纸张/噪点纹理背景；
  - 口播段：轻微暗角/聚光效果，边缘黑色透明度约 30-50%。
- **实现建议**：CSS 多层 `background-image` 叠加（星空 + 噪点 + 暗角）；暗角用径向渐变 `radial-gradient`。
- **是否值得做成可复用模块**：是，建议新增 `TextureBackground` 切换层（星空点 / 浅灰纸张噪点 / 暗角 vignette），按段落类型切换。

## 补充结论

**新增可复用组件建议（5 个）**：

1. `CircularAvatar`：硬边 `clip-path: circle()` + 紫色渐变描边 + 紫色 `box-shadow` 外发光，参数化描边粗细与 glow 半径。
2. `RoundedUIFrame`：圆角矩形 + 2-4px #E0E0E0 实线边框 + 柔和黑色投影，统一 UI 录屏框视觉。
3. `HighlightBox`：圆角矩形 + 2-3px 黄/橙实线描边 + 同色外发光，支持框选区域局部放大（scale 1.05-1.15）。
4. `GlowTitle`：大标题文字使用多层 `text-shadow` / `filter: drop-shadow()` 模拟黄色强辉光与运动模糊 streak。
5. `TextureBackground` 切换层：星空点 / 浅灰纸张噪点 / 暗角 vignette，按段落类型切换。

**核心蒙版配方**：参考视频的视觉处理核心是"**描边 + 外发光 + 投影**"组合，而非复杂 clip-path 或 mask。标签/高亮框/头像的默认视觉配方统一为：实线描边（2-5px）+ 同色或对比色外发光 + 柔和投影。这个配方简单可复用，不需要 SVG clipPath 或 CSS mask-image。

**无需实现的部分**：人物抠像、渐变羽化、背景虚化、复杂几何蒙版。这些参考视频都没使用，本项目也不需要。
