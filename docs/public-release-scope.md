公开版本包含通用规则、按需部署与制作流程、活跃剪辑适配器、测试、共享包装组件及无需外部媒体的技术演示。它不是独立桌面程序，不随源码提供运行时、客户端、模型、字体或作者的媒体工程。

源码中的素材路径或字体回退名称只表示接口/占位，不表示对应文件存在或附带使用许可。历史主题的音效和视频占位不用于默认技术演示。请用自己的授权素材与权威时间轴开始新片；部署按当前缺项触发，不会因第一次 clone 自动全装。

初次打开 Remotion 只登记 PublicSmoke 技术演示，不加载作者旧片。其纯文字和几何图形可验证入口，不证明 ASR、真实媒体、Desktop 连接或最终视频效果已验收。制作成片仍遵循字幕校正和代表静帧确认闸门。

已知平台基线 Windows x64；本地 ASR 已接入 Windows Vulkan 路线。Desktop 桥当前复用 Codex app-server，其他 Agent 能识别项目规则不等于该工具传输已兼容；不承诺所有宿主/平台一键可用。

规则、代码与示例是供有相应权限的 Agent 执行的工作流，不是无需用户登录/授权/审片的无人值守安装器。没有真实新机或真实样本验证的项目必须登记为待验收。
