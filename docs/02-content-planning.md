# 02 内容规划

> 阶段二通用流程。读取校正版时间轴字幕、语义分段、设计文字与图形规划、画面时间轴、字幕避让和信息密度。
> 本阶段不做 Remotion 代码实现，实现见 `03-remotion-production.md`。

## 风格前置

开始规划前，先读[公共规则](./reference-styles/common-rules.md)，再从[风格索引](./reference-styles/README.md)选择本片主风格，并只读取该风格的规则文档与共享基础。不得为了“丰富”而同时套用多个风格的色板、构图和主转场；确需混合载体时，逐段标注主载体和切换理由，不混搭未指定的视觉皮肤。

## 输入

- **当前片主口播**：由预检与用户指定确定，登记视频、独立音频、时长和同步关系，不写死历史素材名。
- **当前片 B-roll / 图表证据**：逐项登记来源、尺寸、内容、烧入字幕状态及适用语义，不假定所有 B-roll 都有字幕或已经对齐。
- **B-roll 处理状态先分流**：按[包装 B-roll 衔接](./workflows/packaging-broll.md)复用已剪好且独立对齐的分轨，继续原包装适配；未处理源才按需加载共用挑选/剪段，直接接回本流程，不默认生成剪映工程。
- **权威时间轴字幕**：规划前按[字幕规则](./workflows/subtitles.md)完成来源核验与校正；本阶段只消费已校正的时间轴，不反向编写替代字幕。
- **风格与片级要求**：从项目登记和用户当前要求确定，人物形状、位置、色板与转场由选定风格决定。
- **参考封面**：仅在实际存在且相关时记录。成片阶段不自动生成封面或发布资料。

原装修素材、秋芝头像与字幕底板配置已单独保留在[装修案例历史配置](./reference-styles/秋芝风/装修案例-历史配置.md)，不作为新片输入或公共要求。

## 一、时间轴读取与字幕策略

校正版时间轴用于两件事：
1. **内容判断**：判断每段讲什么、提取逐句时间码、定位口误与重复；
2. **逐字字幕**：没有源烧入字幕的区间按校正版渲染；已经存在烧入字幕的区间按策略避免双字幕。不强制使用历史 `CaptionBar` 外观。

B-roll 是否显示 Remotion 字幕由实际烧入字幕与当前片策略决定，不按 A/B-roll 名称一刀切。来源、时间轴与显示边界见[字幕规则](./workflows/subtitles.md)。

解析 srt 输出：

- 完整口播文本；
- 逐句时间码（来自 srt）；
- 明显停顿、重读词、转折词（需要时核对音频，不凭文本猜重音）；
- 建议删除或压缩的口误、重复、无效语气词。

不改变说话者原意。

### 叙述视角、语义图标与证据占比

- 动态文字、标签与图标先核对“谁在说／谁受影响／动作指向谁”。相似句式从员工、雇主或其他角色出发时须分别绑定身份，不能把对比双方互换、混成同一人的立场或用同一个角色图标代替。角色依据当前口播与用户明确说明登记在单片计划。
- 身份不等于态度：还要核对“谁受益／希望达成什么”。“替我干掉工作”可能是把任务交给 AI、自己减负，不能仅因说话者是员工就擅自写成失业焦虑；用户澄清后同步修正包装文案、因果动效与当前片计划，不改原声字幕冒充纠正。
- 图标与动效承担实际语义：用对象、操作、因果、流程或身份帮助理解，不能只为填空放装饰。无可靠数字时用关系／流程图，不造数据；标签和图标不得提前展示后句才成立的信息。
- 不影响动态文字的完整表达、字幕、人物及操作 ROI 时，B-roll 证据区尽量放大。先压缩无意义留白、裁掉已确认的外部占位黑底，再移动／减量装饰或适度缩小头像；不靠缩小关键信息字体、遮挡核心控件、拉伸素材或裁掉有效内容来换取更大占比。实际比例逐镜登记与样张核验，不固定套历史小窗尺寸。

## 二、语义拆分信息段

不要按固定秒数平均切割。遇到以下情况可建新段：主题变化、提出新问题、解释原因、给新方法、观点进入案例、出现步骤/数据/对比/结论、明显转折、进入总结或行动建议。

每段原则上只表达一个主要意思。过短且意思连续的合并；过长且包含多个观点的拆开。

每段输出：段号、起止时间码、持续时间、对应口播原文、内容作用、情绪和节奏、是否需要删除口误/停顿/重复。

## 三、为每个信息段设计包装组合

每段统一输出以下内容。

### 1. 口播大意
1-3 句准确概括，不照抄整段字幕。

### 2. 核心传播目标
本段最希望观众记住什么。**只能保留一个**。

### 3. 主要标题
- 4-12 个汉字，准确表达主题；
- 避免空泛和口号化，不写成长句；
- 说明是否整段常驻、是否只在开头显示、何时进入、何时退出。
- 位置服从选定风格与当帧安全区，不强制所有段位于左上。

### 4. 副标题或重点句
补充标题，突出判断、结果或转折。最多两行，不重复大标题。无必要时可取消并说明原因。

### 5. 一句话摘要
说明本段真正想表达什么。判断开头/中途/结尾出现或不显示。

### 6. 信息卡设计
0-3 张，不强制凑满。类型：事实卡、观点卡、步骤卡、数字卡、对比卡、风险卡、结论卡、建议卡。

每张输出：名称、核心内容、类型、来自哪句口播、是否数字强调、出现时机、停留时间、退出方式、是否与其他卡同时显示。

先判断内容是否真的需要“卡片容器”：
- 独立对象、文件、真实证据、需要长期承载两层以上信息的内容才优先使用卡片；
- 简短观点、总结、步骤名和关键词优先考虑边注、流程轨、定位标签、观点重音、编号或直接排版；
- 不允许为了让画面“看起来有设计”而把每句提炼文案都装进圆角卡片。

强制规则：
- 不编造数据/案例；
- 不把字幕原句直接复制成卡片；
- 信息不足不硬凑；
- 每张只表达一个意思。
- 卡片不能只放一条与字幕同构的完整句子；至少通过编号 / 眉题 / 主标题 / 元信息中的两级建立独立层级。
- 卡片字号、字重和行长必须与字幕明显区分，不能让卡片看起来像移动到别处的第二条字幕。
- 黄色边、彩色底和高饱和状态只服从目标风格与具体对象角色；局部方案中的识别边规则不得自动推广到所有卡片。
- 卡片位置由原画视觉重心、负空间、头像区、字幕区和真实 UI 控件共同决定，禁止跨段统一套用同一个 `right / bottom` 固定槽位。

字幕回答"我具体说了什么"，信息卡回答"这一段想让观众理解什么"。两者不能混淆。

### 7. 图表或二维动效
判断本段适合：柱状图、折线图、饼图、数字计数器、前后对比、流程图、时间轴、漏斗图、关系图、路径图、步骤动画、图标组合、产品界面演示、截图展示、关键词二维动效、不需要图表。

输出：推荐形式、使用原因、展示内容、是否存在真实数字、占画面区域、人物是否需缩小/横移/退场、进入顺序、退出顺序。

**数据图表必须有可核对的真实数据源，并对应当前已经成立的语义。用户提供的表格可以作为证据，不要求每个数值都逐字念出；来源、单位、历史状态与场景假设必须保留。无真实数据时用关系、流程或步骤图，不得伪造数值。**

## 四、包装组合选择

不能只写"采用模式 A"。每段必须输出以下四层。

### 1. 主构图模式
从阶段一主构图模式库选择。说明：为什么适合、人物位置尺寸、信息区位置尺寸、是否需段内切换构图。每段原则只有一个主构图，段内允许一次必要切换。

### 2. 内容组件组合
列出实际使用的组件。说明：哪些常驻、哪些分批出现、哪些不能同时显示、哪些只强调一次。不要默认使用全部组件。

### 3. 视觉处理与蒙版
从阶段一视觉处理库选择。每项说明：作用对象、所处图层、解决什么问题、是否直接参考目标视频、哪些参数需根据我方人物和背景调整。蒙版还需说明：形状、位置、尺寸、圆角、羽化、透明度、描边、阴影、进入和退出方式。

原画已经存在自然留白时，优先直接排版，不额外覆盖半屏色层。确需遮罩时只覆盖文字局部，并检查遮罩是否损失人物轮廓、环境纹理、空间光影或形成可见的矩形 / 渐变分界；不得为了文字方便把画面一侧处理成完全不透明的空白板。

### 4. 动效模块组合
从阶段一动效库选择。说明：作用元素、先后顺序、持续时间、运动方向、缓动风格、是否与重音/停顿/转折同步、哪些可同时执行、哪些必须依次执行。

## 五、每段画面时间轴

按本段起点输出相对时间轴，至少记录：
- 校正版字幕的固定偏移与相应句子；
- 本段实际主载体，以及 A/B-roll 的来源和使用区间；
- 标题、关键词、节点、关系线、图表、证据出现与退出的语义依据；
- 人物和字幕安全区如何随构图交接；
- 需检查的入口、中段、到达、保持、退出和段间衔接帧。

时间由真实句边界与操作事件决定，动作由选定风格决定；不套一组固定秒数、半透明面板或头像位置。每条文字注明 `subtitle / title / keyword / summary / label` 角色。

## 六、段内构图切换

仅以下情况建议切换：信息量突然增加、需完整展示流程图/图表、进入案例截图、需突出重要结论、人物明显遮挡核心内容、参考视频中存在相似转换逻辑。

输出：是否切换、切换时间点、切换前后构图、人物如何移动、蒙版如何变化、信息组件如何重排、使用什么过渡动画。
不要为追求视觉变化频繁切换。

## 七、字幕渲染与避让规则

字幕来源、校正、时间换算与显示边界以[字幕规则](./workflows/subtitles.md)为准；本节只规定规划时必须交出的信息：

- 每个区间是否有源烧入字幕；没有时如何按校正版呈现，有时如何避免双字幕。
- 裸排字幕使用的字色、字号、行数和位置，如何适应实际背景；不指定字幕底板或继承角色 / 卡片外观。
- 字幕、人物脸部、ROI、关键数字、图表标签分别占用哪些区域，哪些元素需要移动或减量。
- A/B-roll 交接时保留单一字幕层；有烧入字幕的区间不让另一条字幕以淡化重叠的方式残留。
- 烧入字幕无法重新定位时调整外部包装与头像，不能覆盖或裁掉其内容。

头像尺寸、形状、存在区间和交接动作服从当前片要求及选定风格，不固定左下或圆形。

## 八、信息密度控制

每段明确：

- **常驻元素**：如人物、按实际烧入状态选择的单一字幕层、章节编号；
- **分批出现元素**：如事实卡、步骤卡、图表节点、摘要；
- **只强调一次**：如核心数字、关键词、结论标签；
- **不应同时出现**：如三张事实卡与完整图表、长副标题与 A-roll 字幕区重叠、全屏截图与人物大特写、摘要+卡片+结论同时常驻。

画面优先保证信息理解，而不是堆满所有可用元素。

## 九、参考视频复刻程度

每段分别说明：

- **直接复刻的规则**：构图比例、蒙版揭示逻辑、卡片出现顺序、字幕层级、图表生长节奏等；
- **需要改造的部分**：品牌色、标题长度、人物占比、卡片数量、图表形式、截图尺寸等；
- **不建议照搬的部分**：仅适合参考视频人物姿势的蒙版、与内容无关的装饰、过于复杂的图表、高频无意义动画、需版权素材的设计、影响口播阅读的转场等。

## 十、每段最终输出模板

### 第 X 段：段落名称

**基础信息**：时间码、持续时间、口播原文、口播大意、核心传播目标、内容作用、节奏。

**文案层级**：主要标题、副标题、一句话摘要及各自文字角色。

**信息卡**：卡片 1/2/3，不需要时说明原因。

**图表或二维动效**：推荐形式、展示内容、使用原因、数据来源与实际布局区域。

**包装组合**：主构图模式、内容组件组合、视觉处理与蒙版、动效模块组合、是否段内切换构图。

**元素出现顺序**：按本段相对时间码。

**信息密度**：常驻/分批/单次强调/不应同时出现。

**参考视频对应关系**：直接参考/组合参考/需要改造/不建议照搬。

**制作实现**：可复用组件、新增组件、所需素材、Remotion 实现建议、制作难度（低/中/高）。

阶段二完成后，选出 10-20 秒代表性测试段，进入 `03-remotion-production.md`。
