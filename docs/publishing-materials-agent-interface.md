# 发布视频 Agent 统一取用标准

上游只需告知**片名、风格名、目标平台**。所有位置相对项目根目录，不为每条视频另写路径表。

```text
deliverables/final-videos/<片名>-<风格名>/
├─ <片名>-<风格名>-成片.mp4
├─ <片名>-<风格名>-封面-3x4.png  # 1080×1440
├─ <片名>-<风格名>-封面-4x3.png  # 1440×1080
└─ 发布资料.docx
```

四个文件同层放置。**封面是独立 PNG，不在 DOCX 里，也不建 `cover/` 子目录。**发布 agent 上传本目录的 MP4；根据目标平台当前上传界面的比例与裁切要求，从本目录两张封面中选合适的一张，不跨风格取图。无法确定合适封面时停下询问，不猜。

《发布资料.docx》只含以下固定栏目，不放视频路径、封面路径、图片或其他发布清单：

```text
发布标题：一份，所有平台通用
发布配文：一份，所有平台通用，正文不超过50字
话题标签：一组，所有平台通用
```

发布时所有平台均使用同一标题、配文和标签；标签只按抖音站内话题核验，不代表在其他平台已有同名话题。配文正文按可见字符计数，含标点、空格和英文字符，**不得超过 50 字**；单列标签不计入。平台只有一个文字框时，按「标题 → 配文 → 标签」顺序填写。若 DOCX 缺失、必填栏目为空、标签写着“待核验”、配文超长，或文件与目标风格不符，停止发布并报告，不自行编写或替换。
