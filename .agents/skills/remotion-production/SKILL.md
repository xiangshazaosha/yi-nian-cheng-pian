# 项目制作路由

沿用现有技能名称，不增加第二个发现入口。本技能不维护参数、方案副本或尚未实现的软件控制能力。

1. 遵循根 `AGENTS.md`；已在会话注入或读过且未改变时不再全文读取。
2. 按用户动作与当前阶段查 `docs/workflows/README.md`，只读匹配任务的入口；素材／成片／剪辑请求先按素材入口判定语义，不把预检的技术默认当作用户意图。未进入包装，不加载风格与包装库；发布资料和发送不自动触发。
3. 长文件先定位相关标题、关键词与区间，再读必要内容；执行操作前读完其约束，不为节省上下文遗漏确认闸门或验收条件。
4. 单片内容以已有项目登记、权威字幕与实际素材为准。只查当前片和受影响区间，历史记录按关键词检索。
5. 执行对应入口的验证和停止条件，如实区分已实现能力、待做规划与实际验收；文档维护不创建审片项目。
