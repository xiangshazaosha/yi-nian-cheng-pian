# 用户音效素材的入库与引用

公开版本不含实际音效或制作回执。统一资产索引为 remotion-clone/public/sfx/catalog.json，初始为空；用户自己的授权素材放共享 sfx 目录，按当前影片实际需要引用，不因旧组件预设而自动补齐音效库。

1. 核对来源、许可、声段、格式、时长和哈希；用户提供不等于已核实商用或再分发许可。
2. 对原素材只读，处理母版留在本机共享目录，用稳定 ID，已存在不同哈希时不覆盖。
3. 索引记录实际路径、来源、许可状态、处理步骤、母版哈希及试听状态；不公开私人来源、账号、签名 URL 或实际工程回执。
4. 每片单独记录事件、触发帧、素材内重音偏移、增益及口播余量，不把片级增益烘焙回共享母版。
5. 技术测量不能代替听审。先按 [音效规则](../../docs/packaging-library/sfx-rules.md)验证，未授权不生成音乐、不改变口播或扩大制作范围。

可用公开版保留的 remotion-clone/scripts/import-user-sfx.py；先读取帮助并确认来源、ID、用途及处理范围。文件存在、处理成功不等于已听审。
